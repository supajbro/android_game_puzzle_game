# Release checklist

Status: template for later release work orders.

- [ ] Unity compilation and complete automated suites pass.
- [ ] Portrait Android device smoke test passes.
- [ ] API target, AAB, ARM64 and IL2CPP verified against current official requirements.
- [ ] Owner-controlled application ID and signing configuration supplied securely.
- [ ] Consent, advertising, privacy and data-safety behaviour verified with actual SDK versions.
- [ ] Store art and screenshots are truthful captures from the release build.
- [ ] Outstanding owner actions and release blockers are documented.
